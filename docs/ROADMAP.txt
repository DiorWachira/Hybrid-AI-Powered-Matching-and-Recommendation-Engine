CLIENT ALIGNMENT NOTES (2026-09-20)
====================================================================
 - Backend stays FastAPI (Python). The client mentioned NestJS, but the
   repo already has a working FastAPI backend and the ML/NLP pipeline
   (BERT, Neo4j) is Python-native; migrating would be pure rework.
 - Scope stays the matching/recommendation engine only. The client's
   apply/accept/contract/project/milestone/payment flow is a separate
   freelance-marketplace layer and is deliberately deferred -- see
   docs/extras/marketplace_features.txt for the captured requirements.
 - "Simulate but also be a web app": resolved as a seeded demo/evaluation
   mode inside the web app (data_pipeline/evaluate_model.py running the
   same hybrid engine over the synthetic dataset), not a separate program.
 - Mobile is out of scope entirely.
 - Dataset strategy decided -- see docs/DATASET_STRATEGY.md for the full
   rationale (synthetic Kenyan candidates, real BrighterMonday job posts,
   ESCO skill ontology, optional CDACC mapping).

====================================================================
RISK WATCHLIST
====================================================================
 - Dataset access: BrighterMonday scraper runs cost money and are capped
   per run; keep the synthetic generator as the default path and treat
   scraped jobs as an enrichment, not a hard dependency.
 - Model size vs. latency: a large BERT model on CPU may breach the
   2-5 s target; pre-compute embeddings and consider a smaller model.
 - Python 3.14 compatibility: torch/transformers wheels may lag; be
   ready to run the backend on a 3.12 environment if installs fail.
 - Scope creep on the frontend theme: keep Week 3 shells minimal and
   defer all styling to Week 7.
 - Neo4j ontology breadth: seed only the skill families needed by the
   demo domains (software, data, accounting).
 - Marketplace scope creep: apply/accept/contract/project/milestone/
   payment features stay in docs/extras/marketplace_features.txt and
   are out of this roadmap until the core engine is done.
